## Review Files

- `contact-sheet-normalized.jpg`: quick visual review of the normalized output.

## Excluded / Not Used

- `originals/tencent-myapp.png` is an invalid HTML download and is not used.
- `originals/baidu-mobile-assistant.jpg` is a Baidu promotional banner and is not used.
- `originals/360-mobile-assistant-candidate-*.png` and `originals/360-mobile-assistant-official-hero.png` are promotional page images and are not used in the normalized set.
- Lenovo App Store, PP Assistant, and Anzhi were not included because I did not find a current, clearly traceable logo source suitable for article use during this pass.
